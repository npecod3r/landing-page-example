# Landing Page Example

Адаптивный лендинг, написанный на чистом HTML, CSS и JavaScript без сторонних библиотек.

## Функционал

- Адаптивная верстка под разные разрешения экранов
- Мобильное бургер-меню с переключением состояния
- Интерактивное модальное окно (открытие по кнопке, закрытие по крестику и клику вне области)
- Обработка отправки контактной формы

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript

## Структура проекта

- index.html — основная разметка страницы
- style.css — стили и адаптивность
- script.js — логика бургер-меню, модального окна и формы

## Запуск

1. Клонируйте репозиторий: git clone https://github.com/npecod3r/landing-page-example.git
2. Откройте файл index.html в любом браузере.
